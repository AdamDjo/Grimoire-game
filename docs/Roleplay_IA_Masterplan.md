# Vision Produit — Plateforme de Roleplay IA Persistante

## Concept Principal

Ce n'est pas un simple jeu de rôle IA.

Ce n'est pas un chatbot fantasy.

Ce n'est pas un forum RP.

La promesse principale est :

> Chaque action laisse une trace.
> Chaque personnage se souvient.
> Chaque décision transforme le monde.

L'utilisateur ne joue pas dans une histoire.
L'utilisateur modifie l'histoire.

---

# Objectif de la Landing Page

La landing n'a pas pour objectif de vendre des fonctionnalités.

Elle doit vendre une émotion.

Le visiteur doit se dire :

> Je vais vivre mon propre roman.

et non :

> Je vais tester un outil IA.

# LANDING PAGE (DÉTAILLÉE)

## Principes

Ne pas faire un site classique.

Éviter :

- Features
- Pricing en haut
- FAQ trop tôt
- Cartes marketing génériques
- Design SaaS

La landing doit ressembler à l'introduction d'un roman interactif.

---

# SECTION 1 — HERO

## Objectif

Créer immédiatement de l'émotion.

## Layout

Illustration fullscreen.

Ambiance :

- dark fantasy
- RPG premium
- cinématique
- mystérieuse

### Texte

Titre :

ÉCRIS TON HISTOIRE

Sous-titre :

Un monde vivant.
Des personnages qui se souviennent.
Des conséquences qui traversent le temps.

Description :

Chaque choix influence le monde.
Chaque rencontre peut devenir une légende.
Chaque aventure est unique.

CTA Principal :

COMMENCER L'AVENTURE

CTA secondaire :

Découvrir le monde

## Animation Hero

Pas de vidéo.

Utiliser :

- parallax
- brouillard animé
- particules
- lumière dynamique
- zoom caméra subtil

Le décor doit sembler vivant.

---

# SECTION 2 — LE MONDE SE SOUVIENT

## Objectif

Expliquer la différence avec ChatGPT RP.

### Titre

Le monde n'oublie rien.

### Mise en scène

Trois événements affichés sous forme chronologique.

Exemple :

Tu aides un marchand.
↓
Le marchand prospère.
↓
Sa famille se souvient de toi.

Autre exemple :

Tu trahis une guilde.
↓
La guilde lance une chasse.
↓
Des mois plus tard les PNJ en parlent encore.

Message clé :

Les conséquences persistent.

---

# SECTION 3 — DÉMONSTRATION D'HISTOIRE

## Objectif

Montrer une session réelle.

Format :

Mini histoire interactive.

### Exemple

La pluie tombe sur les pavés.

Une inconnue t'approche.

Choix :

- Lui parler
- L'ignorer
- La suivre

Puis montrer les conséquences.

Le visiteur comprend instantanément le concept.

---

# SECTION 4 — TON PERSONNAGE

## Objectif

Montrer que la création est profonde.

Ne jamais afficher un simple formulaire.

### Message

Ton personnage est construit à travers ses choix.

Montrer :

- Origine
- Race
- Valeurs
- Ambitions
- Secrets
- Relations
- Réputation

Chaque élément influence le monde.

---

# SECTION 5 — LE MJ IA

## Objectif

Présenter le moteur.

### Titre

Un maître du jeu qui n'oublie jamais.

Explication :

Le MJ :

- crée les scènes
- interprète les PNJ
- adapte les événements
- conserve l'historique

Mais surtout :

Le monde évolue même lorsque le joueur est absent.

---

# CRÉATION DE PERSONNAGE

## Ne pas utiliser un formulaire classique

La création est intégrée à la narration.

### Exemple

Archiviste :

D'où viens-tu voyageur ?

Choix :

- Nord
- Désert
- Cités Libres
- Autre

Puis :

Quel peuple t'a vu naître ?

Puis :

Qu'espères-tu accomplir ?

Puis :

Quelle est ta plus grande peur ?

À la fin :

Le personnage est généré automatiquement.

---

# PREMIÈRE SESSION

## Objectif

Créer une émotion.

Pas un tutoriel.

Pas une fiche technique.

Le joueur doit :

- faire confiance
- hésiter
- prendre une décision

L'émotion prime sur les mécaniques.

---

# MONÉTISATION

## Gratuit

- création personnage
- début d'aventure
- quelques campagnes

## Premium

- mémoire étendue
- plusieurs personnages
- illustrations avancées
- univers privés
- campagnes longues
- compagnons IA

Le premium approfondit l'expérience.

Il ne bloque pas le jeu.

---

# FIDÉLISATION

## Journal vivant

Après chaque session :

Résumé automatique.

## Monde persistant

Pendant l'absence du joueur :

- événements
- lettres
- rumeurs
- évolution des factions

## Notifications

Exemples :

Elara cherche à te retrouver.

La ville que tu as sauvée est attaquée.

Le conseil souhaite te rencontrer.

# RÈGLE ABSOLUE

Le joueur ne doit jamais avoir l'impression :

"Je remplis un formulaire."

ou

"Je teste un chatbot."

Il doit avoir l'impression :

"Je viens de commencer le premier chapitre de mon propre roman."

# A faire

Mon conseil pour la suite : avant même de coder, il faudrait maintenant produire un Game Design Document (GDD) complet de 30 à 50 pages qui détaille :

la mémoire du monde
le système de PNJ persistants
les factions
les relations
la réputation
les événements dynamiques
les boucles de rétention
les mécaniques premium
le fonctionnement exact du MJ IA
